# 실험 코드 안내

CISC-W'26 논문의 SITL 실험에 쓴 코드 전부. 2026-08-30 기준.

**정본은 공개 저장소** `~/uav-control-effect-window/pipeline/` 이다.
이 폴더는 그 사본이며, 코드를 고칠 일이 있으면 저장소 쪽을 고치고 여기로 복사한다.

---

## 실행 순서

```bash
export ARDUPILOT_PATH=/path/to/ardupilot

# SITL 기동
cd $ARDUPILOT_PATH
./build/sitl/bin/arducopter -S -I0 --model + --speedup 1 \
    --defaults Tools/autotest/default_params/copter.parm \
    --home 34.7604,127.6622,0,0 &

# 비행 1회 (조건 이름, 반복 번호)
python3 repeat.py BASELINE 1

# 분석만 재현 (SITL 불필요) — 논문 표와 통계값이 그대로 나온다
python3 analyze_repeat.py
```

---

## 핵심 4개 — 이것만 보면 실험이 이해된다

| 파일 | 하는 일 |
|---|---|
| `runtime.py` | **모든 실행의 기반.** MAVLink 관측, 술어 표시, 판정, 결과 저장. tlog 기록 |
| `repeat.py` | 사전 등록한 반복 측정 실행기. 논문 표 3의 25비행이 여기서 나왔다 |
| `analyze_repeat.py` | 사전 등록 분석. Mann-Whitney 정확검정, Holm 보정, TOST |
| `nojam_test.py` | **무재밍 대조군.** 재밍이 없을 때 회수 명령이 수락되는지 확인 |

## 공격그래프와 시나리오 생성

| 파일 | 하는 일 |
|---|---|
| `graph.py` | 술어 정의와 경로 열거 |
| `generate.py` | 경로를 시나리오로 전개 (언어모델) |
| `baseline_template.py` | 결정론적 템플릿 전개 — 생성 방식 대조군 |
| `gates.py` | 정적 게이트 G1 스키마 · G2 술어 어휘 · G3 변환 가능성 |
| `to_script.py` | 통과한 시나리오를 실행 스크립트로 변환 |

## 주의

- **원고를 만드는 코드는 여기 없다.** `01_원고/원고제작도구/` 에 따로 있다
  (`md2docx.py` 원고→DOCX, `pagecount.py` 쪽수 확인, `genfigs_bw.py` 그림 생성 등)
- `runtime.py` 의 `preflight()` 가 `SIM_GPS1_JAM = 0` 으로 초기화한다.
  재밍 조건은 그 뒤에 `setp("SIM_GPS1_JAM", 1)` 로 만든다. `nojam_test.py` 는 이 단계를 건너뛴다
- `analyze_repeat.py` 는 사전 등록 범위인 `rep 1~5` 만 받는다. 그 밖의 번호는 분석에 넣지 않는다
- 원시 tlog 보존은 측정을 마친 뒤 추가한 기능이라 25비행분이 없다
